# このフォルダーの出どころ

Sprint Coder のデスクトップ操作の実行ファイルは、このフォルダーのソースから build している（repo の root の `build-desktop-control.mjs`。出力は Windows が `build/Release/sprint-coder-desktop-control.exe`、macOS arm64 が `build/Release/sprint-coder-desktop-control` と、それぞれの SHA-256 を書いた `.sha256`）。

- 出典: 名前と URL、取り込んだ tag と commit は、repo の root から見て `docs/licenses/desktop-control-license.txt` に書いてある（Apache License 2.0。全文は同じフォルダーの `LICENSE` と、その文書。upstream に NOTICE は無い）
- 版: 1.2.0（`Cargo.toml` の `version = "1.2.0"` に一致）
- 取り込んだ日: 2026-11-10
- 取り込み方: 出典の文書に書いた commit の git の中身（改行は LF のまま）を、元の構成のままコピーした。
- macOS の取り込みは 2026-11-15。同じ upstream commit の `crates/macos` を、内容を変えずに独立した commit で取り込んだ。その後の変更は下の表に記載した。

以後の変更は、この repo で行い、下の「変えたファイル」に書き足す。upstream の更新を取り込む時も、ここに版と commit を書く。

## 入れたもの

Windows と macOS arm64 用の CLI の build に要る部分。

- `Cargo.toml`（workspace）、`Cargo.lock`、`rust-toolchain.toml`（1.89.0）、`LICENSE`
- `crates/core`、`crates/windows`、`crates/macos`
- `src`（CLI。upstream の試験のコードも含む）
- `skills`（`crates/core/src/commands/skills.rs` が `include_str!` でバイナリに埋め込む説明書。macOS・Linux・FFI の分も埋め込まれるので全部入れた）

## 入れなかったもの

`crates/linux`、`crates/ffi`、`apps`（説明のサイト）、`npm`、`benchmarks`、`probes`、`assets`、`docs`、`tests`、`scripts`、`.github`、`.githooks`、`.agents`、`.claude`、`.git`、root の説明の文書（`README.md`、`AGENTS.md`、`CHANGELOG.md`、`CONCEPTS.md`、`CONTRIBUTING.md` など）、`clippy.toml`、`deny.toml`、`.gitleaks.toml` など build に要らない設定。

macOS のソースは取り込み済み。macOS（Apple シリコン）では、アプリ側で有効にしてあり、配布物にも実行ファイルを入れている。macOS でまだ無いのは、clipboard helper と `launch --url` で、別の段階で扱う。カーソルの表示（Team のカーソルを含む）は 2026-11-16 に有効にした（下の表の `crates/macos/src/system/cursor_overlay/` の行）。

build にも同梱にも使わないファイル（2026-11-11）。

## build と試験

- build は repo root の `node build-desktop-control.mjs`。Windows x64 は従来の `cargo build --release --locked`、macOS arm64 はそれに、`-p` で CLI の package の指定を加える。`rust-toolchain.toml` が効くようにこのフォルダーで動かす。ほかの OS と arch は何もせずに成功で終わる。
- macOS の crate の試験は `cargo test --locked --lib` に `-p` で macOS の crate を指定して回せる（socket・process の一覧・Accessibility を使う一部の試験は、実行する環境の許可が要る）。CLI の package の試験は、入れなかった `tests`・`docs`・`.github` などのファイルを `include_str!` で読むものがあるので、このままでは compile できない。Sprint Coder の CI でも回していない。
