Reserved Font Name "PlemolJP" and the WOFF2 conversion. The OFL FAQ (openfontlicense.org/ofl-faq,
2.2-2.2.2) says a WOFF/WOFF2 version may keep the font's name, and is not a Modified Version, "only
if the original font data remains unchanged except for WOFF compression" and WOFF metadata is
either omitted or carries the original metadata unaltered. Checked on both files by decoding the
WOFF2 back with fontTools and comparing with the TTF:
  - the same 19 tables; every table other than glyf/loca/head is byte-identical;
  - all glyphs (24136 Regular, 24172 Bold) compile to identical bytes;
  - head differs only in flags bit 11, which the WOFF2 specification sets on fonts whose glyf
    table went through its lossless transform, and in checkSumAdjustment;
  - no WOFF metadata block and no private data block.
So the conversion is WOFF compression only, and the name is kept as the FAQ allows.
