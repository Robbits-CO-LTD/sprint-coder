# macOS のデスクトップ操作の残りの確認（2026-11-17 夕方）

`macos-desktop-control-leftovers-20261117.md` の続き。スクリーンショットを AI に画像で渡す変更（#1342）、窓を閉じたまま動いているアプリへの対応（#1346）、説明書と CLI の表示から取り込み元の名前を外す変更の、実機の記録。

## 環境と、この記録の位置づけ

- macOS 27.0.1（Apple シリコン）。開発版（dev build）。オーナーが同じ Mac を使っている最中に流した。
- 「CLI を直接実行」は、その PR の build の実行ファイルを、開発版の Electron の子として 1 コマンドずつ実行したもの。「製品の経路」は、開発版の Sprint Coder（隔離した profile）の中の実際の AI が、承認カードを経て実行したもの。
- 実際の AI は Codex CLI（0.153.4）の接続で、モデルは GPT-5.6-Terra を明示して選んだ。Task の設定は「確認する」。必須 Skill の正式な lane（Claude Opus 5.5 / Claude CLI、GPT-6.1 Terra / Codex CLI）は実行していない。
- **この記録の製品の経路は、入力とカードの許可を、debug の口（remote debugging）からの入力イベントで行った。Computer Use での操作ではない。** オーナーが全画面のアプリを使っていて試験の窓が別の Space にあった時は、Computer Use の操作が断られる（窓をこちらの Space に持ってくると、オーナーの画面の上に出る）。最後の 1 回は、試験の窓を画面に出さないために、隠した状態で起動した。
- そのため、**この記録の PASS は補助の結果**で、Computer Use の検証ケースとしては `NOT_RUN`。確かめたのは、画面の操作ではなく、AI に何が届き、何が保存され、AI が何を実行したか。
- 試験用のアプリ（自作。窓は利用者の窓の後ろに置く）: 窓を閉じても動き続けて開き直しの依頼で窓を出すもの（依頼を無視する・最小化する・自分から前面に出る、を切り替えられる）、買い物のメモと「AI への指示」の 2 行を出すもの。

## 3. 説明書と CLI の表示から、取り込み元の名前を外す（[PR #1355](https://github.com/Robbits-CO-LTD/sprint-coder/pull/1355)）

- build した実行ファイルの出力（説明書の全部の名前・別名・参照、全部のコマンドの `--help`、`--version`、`status`、失敗する呼び出し）を、取り込み元の名前（区切りと大文字小文字を問わない）で検索して 0 件。古い名前をわざと渡した呼び出しが、その名前を返すだけ。
- 製品の経路（build `a0a18126`）: 「計算機を起動して、snapshot で表示の数字を読み、閉じる」を頼んだ。AI は `skills get desktop`（返った説明書は `desktop-control`）と `skills get platform`（`desktop-control-macos`）を読み、`launch` → `snapshot` → `close-app` を実行して、数字を正しく答えた。5 つとも exit 0。保存された出力と AI の返事に、取り込み元の名前は 0 件。
- Windows の crate の文も変えている。Windows の build と試験は、その branch の全体の CI で確かめた（28 成功、2 skip。実機では確かめていない）。

## この確認の間にオーナーの Mac で起きたこと

- 試験用の Sprint Coder を裏で 4 回起動した。3 回はオーナーが全画面のアプリを使っている間で、窓は別の Space に出た。最後の 1 回は、隠した状態で起動した。build のための起動（数秒で終了）も 3 回ある。
- 計算機を数回、試験用のアプリを 2 種類、裏で起動して終了した。
- 自分から前面に出る場面の確認で、試験用のアプリが、合わせて約 0.2 秒、前面のアプリになった（入力が無い時を選んだ）。
- `~/Applications` に置いた試験用のアプリは、確認の後に消した。
