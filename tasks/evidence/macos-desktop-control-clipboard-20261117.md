# macOS のクリップボードの書き込みの実機の確認（2026-11-17）

[PR #1338](https://github.com/Robbits-CO-LTD/sprint-coder/pull/1338) を merge するまでと、merge の後の実機の記録。

## 環境と、この記録の位置づけ

- macOS 27.0.1（Apple シリコン）。オーナーが同じ Mac を使っている最中に流した。
- 「製品の経路」は、開発版（dev build）の Sprint Coder（隔離した profile）の中の実際の AI が、承認カードを経てコマンドを実行したもの。カードは、開発エージェントが Computer Use で押した。
- 「CLI を直接実行」は、実行ファイルを、開発版の Electron の子として 1 コマンドずつ実行したもの。製品の承認カードは通らない。
- 実際の AI は Codex CLI の接続で、モデルは GPT-5.6-Terra を明示して選んだ（記録された要求の ID は `gpt-5.6-terra`。解決された ID の欄は空）。必須 Skill の正式な lane（Claude Opus 5.5 / Claude CLI、GPT-6.1 Terra / Codex CLI）は、試験用の profile のモデルの一覧に無く、実行していない。**この記録の PASS は、正式な lane ではない補助の結果。**
- クリップボードの中身は、一度も読んでいない。変わったかどうかは、変更回数と型の名前の一覧だけで見た。
- 記録の取り方: クリップボードの変更回数を 20 ms ごと、実行ファイルの process を 10 ms ごと、アプリの前面の切り替えの log、画面の窓の順番。
- クリップボードを変えたのは、合わせて 3 回（1 の 6、2 の 12、3 の最後の行）。1 回目はオーナーが「1 回上書きしてよい」と了承した。2 回目と 3 回目は、オーナーが「毎回の確認は要らない」と答えた後に行った。3 回目は、空のクリップボードに対する消す操作。

## 2. `/Applications` の配置（CLI を直接実行、head `2597208f`）

`/Applications` の直下に一時のフォルダー（利用者の持ち物・権限 755）を作り、本体・helper・封印を copy して実行した。確認の後に消した。

| #   | 確かめたこと                                                        | 結果 | 実際に起きたこと                                                                                                                                                                                                                                                                                                     |
| --- | ------------------------------------------------------------------- | ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 11  | 元の検査のままだと、`/Applications` の下の helper は断られる        | PASS | 同じフォルダーに、本体を別の名前で copy して `clipboard-clear` を実行（Sprint Coder の名前ではないので、元の検査が効く。helper も、取り込んだコードの既定の名前で copy）。exit 1、`not_delivered`、理由は「Helper path crosses a directory writable by an untrusted principal: /Applications」。変更回数は変わらない |
| 12  | Sprint Coder の名前では、同じ場所の helper が起動し、消す操作が通る | PASS | `sprint-coder-desktop-control clipboard-clear` を実行。exit 0、0.3 秒。変更回数は 18 → 19 の 1 回だけ。消した後の型の一覧は空。helper は 0.19 秒以内に終わり、残らない                                                                                                                                               |
| 13  | 前面を取らない                                                      | PASS | 実行の前後で、画面の窓の順番は同じ。実行の間に、前面の切り替えの記録は無い                                                                                                                                                                                                                                           |

- 12 が、緩めた検査を実際に通った最初の起動。11 と 12 で違うのは、実行ファイルの名前（どちらの検査が効くか）だけ。
- 消す操作の結果は `delivered_unverified`（書き込みは `delivered_verified`）。取り込んだコードが、消す操作を Windows でも同じ値で返す作りのため。空になったことは、外から型の一覧で確かめた。

この Mac の実際のフォルダーの値で、検査の関数を動かした結果（一時的な試験。commit していない）:

| フォルダー                                                        | 持ち主・group・権限 | 元の判定 | 足した判定 | 書き込みを許す ACL |
| ----------------------------------------------------------------- | ------------------- | -------- | ---------- | ------------------ |
| `/Applications/<アプリ>.app/Contents/Resources` と、その上の 2 つ | 利用者・admin・755  | 通る     | 通る       | 無い               |
| `/Applications`                                                   | root・admin・775    | 断る     | 通る       | 無い               |
| `/`                                                               | root・wheel・755    | 通る     | 通る       | 無い               |
