このページでは「repositoryのversion」と「ユーザーが取得できる公開Release」を区別します。mainの開発が先へ進んでいても、tagとGitHub Releaseが公開されるまでは最新正式版として扱いません。変更内容、既知の注意事項、全asset一覧はGitHub Release v0.8.0を正本として確認してください。

GitHubで公開中の最新正式Release（Latest）です。公開日は2026年11月15日です。macOS向けの配布物は、v0.8.0にはまだありません。macOSは現在v0.6.0です。v0.8.0は準備中です。

v0.8.0 の変更点

GitHub Release v0.8.0 に記載した主な変更です。正式版 0.6.0 以降の変更をまとめています。すべての変更と既知の注意事項は公開ページで確認できます。

  • デスクトップ操作（Windows）を追加。AIが起動中のアプリの画面を読み、ボタンを押し、文字を入れ、メニューを実行。操作は利用者の前面を奪わずに裏で進行
  • アプリを名前で起動し、ブラウザーはURLを指定して新しい窓で表示。承認カードに対象のアプリ・部品・動きを表示
  • TeamのWorkerにもデスクトップ操作を任せられる（1つのTaskで同時に3人まで）。Workerごとに色の違うカーソルを表示
  • Setupを作り直し。ロゴの演出の後、7つの手順で、使うAI・返事の仕方・Teamの使い方を選択
  • 返事の仕方（言葉づかい・長さ・説明のしかた・言語・進め方）と、Teamの使い方（言った時だけ／おまかせ／積極的に）の設定を追加
  • テーマ（黒・灰色・白）を追加。サイドパネルを作り直し、UI・ログ・コードのフォントを同梱
  • 取り消された承認カードを履歴に保持。失敗したTeamのあるTaskで、もう一度Workerを雇える
  • URL・hash・IDを含む依頼が、秘密の検査で誤って拒否される問題を修正

過去の試作版（pre-release）

v0.7.0-beta.15は2026年10月19日（日本時間）に公開した試作版です。正式版 0.6.0 より前の公開内容で、バージョン番号が大きくても機能が新しいとは限りません。0.7.0-beta系から0.6.0への切替は自動更新の対象になりません。

このサイトの映像は、2026年10月20日時点の開発中buildで収録しています。そのため、正式版 0.8.0 の画面とは異なる場合があります。過去のものを含む全ReleaseはGitHub Releasesの一覧で確認できます。

ダウンロードしたファイルを確認する

GitHub ReleaseにはassetごとのSHA-256 digestが表示されます。ダウンロード後のファイルをOSのcommandで計算し、Release画面の値と一致することを確認できます。

macOS

shasum -a 256 Sprint-Coder-0.6.0-arm64.dmg

Windows PowerShell

Get-FileHash .\Sprint-Coder-Installer-0.8.0.exe -Algorithm SHA256

利用前に確認すること

macOS版は、v0.8.0にはまだ含まれていません。macOSはv0.6.0のままで、自動更新も行われません。準備ができしだい、v0.8.0のReleaseに追加します。v0.6.0からは、アプリ内の更新、または公開ページの配布物で更新できます。

以前の「Computer Use（ベータ）」は、「デスクトップ操作」に置き換わりました。デスクトップ操作はWindowsだけで使えます。

v0.6.0で、アプリ内のモデル取得・インストール・実行機能を終了しました。既存のモデルファイル、途中のダウンロード、履歴、保存済み選択は保持されます。内蔵モデルを選択していたTaskは「モデルと接続」から別のProviderを選択してください。

Sprint Coder 0.8.0 は正式版です。機能、データ形式、配布方法は今後変更される可能性があります。重要なrepositoryで使用する前に、差分と承認内容を確認してください。現在の開発版ソースコードはPolyForm Perimeter 1.0.1でGitHubに公開されています。公開済みの配布物には、各版に同梱されたライセンスが適用されます。
