v0.6.0 の変更点

GitHub Release v0.6.0 に記載した主な変更です。すべての変更と既知の注意事項は公開ページで確認できます。

  • GraphとMissionで担当・依存関係・変更範囲を確認し、中断した工程や成果統合を再開
  • AI Teamの同時実行数を初期値50、設定範囲1〜100へ拡張。担当カード、全体表示、成果の統合処理を改善
  • Claude Code CLI・Codex CLIから利用可能なモデル一覧を自動取得し、Grok CLIにも対応
  • 読みやすいChatとWorkerスレッド表示、サイドバーの幅変更と⌘B／Ctrl+Bによる開閉に対応
  • Windowsのファイル操作、長いパスやCRLF、複数フォルダーのProjectでの操作を改善
  • 権限変更後の停止確認、承認待ちの表示、完了通知の再配送を改善
  • アプリ内のローカルモデル管理を終了。外部のOllama・LM Studio・LocalAI接続は継続
  • Windowsインストーラーのファイル名にバージョンを追加

このサイトの映像は、2026年10月20日時点の開発中buildで収録しています。そのため、正式版 0.6.0 の画面とは異なる場合があります。過去のものを含む全ReleaseはGitHub Releasesの一覧で確認できます。

ダウンロードしたファイルを確認する

GitHub ReleaseにはassetごとのSHA-256 digestが表示されます。ダウンロード後のファイルをOSのcommandで計算し、Release画面の値と一致することを確認できます。

macOS / Linux

shasum -a 256 Sprint-Coder-0.6.0-arm64.dmg

Windows PowerShell

Get-FileHash .\Sprint-Coder-Installer-0.6.0.exe -Algorithm SHA256

現在の配布状態

  • 最新の正式Releaseはv0.6.0
  • 過去の試作版としてv0.7.0-beta.15を公開中
  • repositoryのmainは次versionへ進む場合がある
  • 未公開versionを正式Releaseとして案内しない
  • 新しい正式Release公開時に、このページとsitemapの更新日を更新する

ソースから最新mainを試す場合ははじめ方を参照してください。ただし、正式Releaseより新しいmainには開発途中の変更が含まれる可能性があります。

利用前に確認すること

アプリ内のモデル取得・インストール・実行機能を終了しました。既存のモデルファイル、途中のダウンロード、履歴、保存済み選択は保持されます。内蔵モデルを選択していたTaskは「モデルと接続」から別のProviderを選択してください。

Computer Useは引き続きベータ機能で、既定はOFFです。対応OS・署名済みビルドなどの利用条件があり、全機能の受入確認は継続中です。未署名のWindows版では利用できません。

Sprint Coder 0.6.0 は正式版です。機能、データ形式、配布方法は今後変更される可能性があります。重要なrepositoryで使用する前に、差分と承認内容を確認してください。ソースコードはMIT LicenseでGitHubに公開されており、配布物またはソースから試せます。
