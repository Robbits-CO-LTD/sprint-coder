ダウンロードしたファイルを確認する

GitHub ReleaseにはassetごとのSHA-256 digestが表示されます。ダウンロード後のファイルをOSのcommandで計算し、Release画面の値と一致することを確認できます。

macOS / LinuxSHA-256
$ shasum -a 256 Sprint-Coder-0.3.0-arm64.dmg
Windows PowerShellSHA-256 
PS> Get-FileHash .Sprint-Coder-Installer.exe -Algorithm SHA256
