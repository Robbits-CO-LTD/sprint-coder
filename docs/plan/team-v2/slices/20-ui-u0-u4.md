## U0 completion

U0は2026-07-28にコード変更なしで完了した。Claude CLI委託は設定modelだけを使った
読み取り専用の2回目を採用し、変更0ファイル、差分0行、test未実行である。

- Mainの`settings.getRuntime`はCodex／Claudeをprobeし、選択Runtimeのmodel一覧を同じ
  `runtimeSettingsSchema` payloadで返す (`ipc.ts:354-387`)。
- RendererはTask非依存の単一`runtime` stateを持ち、model選択を楽観更新して失敗時に戻す
  (`appStore.ts:777-825`)。P1AのTask／Agent canonical selectionを読むRenderer IPCはまだない。
- Composer Pickerは`role="menu"`／`menuitemradio`とEscape closeを持つが、Arrow移動、
  roving tabindex、open時focus、close時focus restoreを持たない (`Composer.tsx:438-515`)。
- Settingsはnative selectへ全modelを同期renderする (`SettingsDialog.tsx:142-157`)。
- 現契約はmodel配列を32件へ制限する (`contracts/src/index.ts:1442-1467`)。Composer、
  Settingsとも全件renderで、検索、pagination、virtualization、revision indexがない。
- E2Eは固定model IDのclickとrestart復元を検査するが、Model PickerのArrow操作、
  active descendant、1000+ catalogを検査しない
  (`model-and-access-settings.spec.ts:20-44,105-125,165-180`)。

U1は既存`runtimeSettingsSchema.models`を拡張して使わず、Main-owned catalog queryとcanonical
selection IPCを先に追加する。Rendererのmembership判定でpage外modelを拒否してはならない。
