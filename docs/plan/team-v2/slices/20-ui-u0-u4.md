# UI Slices U0–U4

| Slice | Outcome | Legacy Picker | Gate |
|---|---|---|---|
| U0 | current UI／state／a11y仕様 | 維持 | 調査文書 |
| U1 | V2をflag OFF既定で追加 | 維持 | 1000件、仮想化、catalog-only |
| U2 | OFF／ON parity | 維持 | Chat／Team／restart／packaged |
| U3 | V2 default ON | fallback | 3OS、a11y、全E2E |
| U4 | legacy cleanup | 削除 | 独立PR、blocker 0 |

UI設計・実装は[UI Agent delegation process](../../../process/ui-agent-delegation.md)に従い、
`claude -p --model "$UI_DELEGATION_MODEL"`へSlice単位で委託する。backend contract、security、
test、merge判断はメインAgentが所有する。
