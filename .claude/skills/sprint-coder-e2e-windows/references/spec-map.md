# Computer Useのケース選択

ケースの正本は [Computer Use検証チェックリスト](../../../../docs/testing/computer-use/README.md)。旧テストごとの前提・操作・期待値・OS・証拠と対応をここから参照する。

変更した画面・操作・境界に関係するケースを選ぶ。Task / Composer、設定、Projectとファイル、承認、Team / Graph、再起動、keyboard / accessibility、性能、公式サイトを対象に、未実施ケースと理由を結果に明記する。チェックリストの操作が現行UIと異なる場合は期待値の根拠を確認して更新し、必要な保証を弱めない。
